About Our Project

Personal Expense Tracker is a simple website that helps users record their income and expenses. It was created for our CPIS-358 course.

The website allows users to add transactions, check their balance, and see their spending.

Project Features

Project Features

  • Add income and expenses
  • Choose a category for each transaction
  • Delete transactions
  • Save transactions in the browser
  • View your balance and recent transactions

Dashboard Features

The Dashboard shows a simple summary of your financial information.

  • Available Balance
  • Total Income
  • Total Expenses
  • Last 5 Transactions
